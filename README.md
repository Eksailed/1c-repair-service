# Сервисный центр на 1С

Учебная конфигурация для ремонта техники. Приёмщик оформляет заявку, мастер проводит диагностику, клиент согласует смету. Запчасти можно зарезервировать на складе или заказать у поставщика. При завершении ремонта 1С списывает детали и позволяет открыть заказ-наряд.

**Стек** · 1С:Предприятие 8.3.27.1508 · BSL · управляемые формы · регистры · СКД

## Что показать за три минуты

| Действие | Что видно в 1С |
| --- | --- |
| Открыть заявку на монитор Марии Орловой | Диагностика, согласованная смета на 2 000 ₽ и срок ремонта |
| Сформировать «Запчасти на складе» | По шлейфам дисплея — **7 на складе, 1 в резерве, 6 доступно** |
| Сформировать «Что ждём от поставщиков» | Заказано 5 шлейфов, получено 3, осталось 2 |
| Открыть готовую заявку на ноутбук | Заказ-наряд с двумя списанными разъёмами. В списке заявок есть связанное гарантийное обращение |

## Запуск

1. Скачай [демобазу с вымышленными данными](ЗаявкиНаРемонт-Резервы-Демо.dt). Для чистой установки доступна [конфигурация без данных](ЗаявкиНаРемонт-Резервы.cf).
2. Создай отдельную пустую файловую базу и открой её в Конфигураторе.
3. Для файла `.dt` выбери «Администрирование → Загрузить информационную базу». Для файла `.cf` выбери «Конфигурация → Загрузить конфигурацию из файла», затем нажми F7.
4. Запусти базу в тонком клиенте и открой раздел «Сервис».

## Проверки и замеры

При установленных Python 3 и 1С:Предприятии выполни из папки проекта:

```powershell
python -X utf8 tests/проверка-портфолио.py
python -X utf8 tests/проверка-портфолио.py --benchmark
```

Для другой установки платформы укажи путь к исполняемому файлу через `--exe`. Скрипт восстанавливает `.dt` во временной базе. Функциональный прогон проверяет отказ при нехватке деталей, откат резерва, согласование сметы и частичные поставки.

| Позиций в отчёте | 102 | 402 | 902 |
| --- | ---: | ---: | ---: |
| Медиана из 7 запусков | 24 мс | 35 мс | 56 мс |

Замер включает компоновку и вывод в таблицу значений на файловой базе в одном сеансе. Кнопки формы и конкуренция двух сеансов в этот прогон не входили.
