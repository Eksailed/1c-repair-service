# Закупка запчастей под ремонт

Статус: сделано, 19.11.2026. Добавлены заказ поставщику, частичные поступления и отчёт по ожидаемым поставкам. Консольные проверки на базе, восстановленной из демовыгрузки, прошли. Открытие формы по кнопке и интерактивную расшифровку отчёта в тонком клиенте не проверяли.

Связано: [о проекте](../README.md), [учёт запчастей](plans/учёт-запчастей.md), [заполненная демобаза](../ЗаявкиНаРемонт-Резервы-Демо.dt).

## Заказ из заявки

Сохрани заявку с деталями, затем нажми «Заказать недостающее». 1С откроет новый заказ со ссылкой на заявку. Для каждой детали из потребности вычитаются текущий остаток и количество, которое ещё ждём по заказам этой заявки. Например, при потребности 4 и остатке 3, если открытых заказов нет, в новый заказ попадёт 1 штука. Выбери поставщика и запиши заказ.

## Частичные поставки

В разделе «Поступления запчастей» создай документ, выбери заказ и укажи фактически принятые детали. При проведении 1С сверяет количество с остатком к получению по заказу. Несколько проведённых поступлений складываются. Перепроведение заменяет прежнее поступление, отмена возвращает количество в остаток к получению. Прежние документы без заказа по-прежнему можно проводить на склад.

## Что показать в демобазе

У поставщика «РемКомплект» заказано 5 шлейфов дисплея, из них 3 уже оприходованы. В отчёте «Что ждём от поставщиков» выбери «РемКомплект». По связанной заявке на монитор видны заказ, поставщик и остаток к получению 2. Дополнительное поступление на 3 штуки должно получить отказ. Поступление на 2 штуки закрывает позицию, после чего она исчезает из отчёта.

Заказ показывает ожидаемую поставку. Детали попадают на склад при проведении поступления. Резервы учитываются при расчёте недостающих деталей.
